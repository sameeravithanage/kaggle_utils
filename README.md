# Kaggle Utils for tree based models

This repo contain the code for data preprocessing, tree-based model training and tracking with _MlFlow_ and fine-tuning models on gpu using _cuML_.

**data folder** - Utils for preprocessing/ encoding and visualising the data.
**models folder** - Utils for training, tuning using gpu and tree model diagnostics

Usage examples can be found here: https://github.com/sameeravithanage/Kaggle
